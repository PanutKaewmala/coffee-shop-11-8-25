# Coffee Shop POS / Management System

A practice web application for managing a small coffee shop business.

This project was built to practice real-world web application development, including system flow planning, database usage, authentication, POS flow, dashboard pages, and AI-assisted development workflow.

## Overview

This system is designed for a coffee shop / drink shop that needs basic tools for managing menu items, orders, stock, branches, and dashboard data.

The project includes three main sections:

- **Public Website** for customers to view shop information
- **POS System** for creating orders and testing checkout flow
- **Admin Dashboard** for managing business data

## Key Features

- User authentication
- Shop / branch context
- Role-based access concept
- Menu management
- POS / order checkout flow
- Stock management concept
- Order and dashboard pages
- Supabase database integration
- Responsive web UI
- Deployment with Vercel
